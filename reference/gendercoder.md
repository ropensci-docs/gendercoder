# gendercoder: A Package for Recoding Freetext Gender Data

Provides dictionaries and
[`recode_gender()`](https://docs.ropensci.org/gendercoder/reference/recode_gender.md)
to allow for easy automatic coding of common variations in free-text
responses to the question **"What is your gender?"**
